# Primer Proyecto de Android: Conexión y Uso de MapView

Este es mi primer proyecto desarrollado en **Android Studio**, donde estoy aprendiendo a construir una aplicación Android utilizando **Java**. El objetivo principal del proyecto es crear una aplicación que se conecte a través de una API para mostrar y trabajar con mapas interactivos utilizando **MapView**.

## Funcionalidades Principales

- **Conexión a la aplicación**: Utilización de las capacidades de Android para conectar la app con fuentes de datos externas.
- **Integración de MapView**: Implementación de **MapView** para mostrar un mapa interactivo. El mapa permitirá interactuar con ubicaciones, hacer zoom y mostrar marcadores personalizados.
- **Uso de Java**: Todo el código de la aplicación está desarrollado en **Java**.

## Tecnologías Utilizadas

- **Android Studio**: IDE oficial para el desarrollo de aplicaciones Android.
- **Java**: Lenguaje de programación utilizado para desarrollar la aplicación.
- **MapView**: Componente de Android utilizado para mostrar mapas interactivos sin necesidad de usar un fragmento completo de Google Maps.
- **Google Maps API**: API utilizada para integrar funcionalidades de mapas en la app (aunque MapView no es un fragmento de Google Maps, aún puede interactuar con la API de Google Maps para funciones avanzadas como la visualización de mapas).
- **Firebase** (opcional si decides integrar alguna base de datos o autenticación).
